# 🍱 飯飯之輩

給部隊打飯班用的便當分箱計數工具。貼上班長傳的訊息 → 自動算出每連幾箱幾個 → 一個一個按 `+1` 裝箱，換層、換箱、換連隊都會自動提醒。

**線上使用：** https://b09901017.github.io/army-meal-box-tracker/

手機瀏覽器打開後，可以「加到主畫面」，用起來就跟 App 一樣（也支援離線）。

---

## 解決什麼問題

打飯的時候最容易出包的三件事，這個工具都幫你顧著：

| 痛點 | 這裡怎麼處理 |
|---|---|
| 還差幾個便當要打？ | 最上面一個超大數字，隨時看得到 |
| 這連打到第幾箱、第幾個了？ | 每連獨立顯示「第 2 / 3 箱、本箱 15 / 24 個、還差 24 個 ＋1 素、差 1 箱 ＋1 素」 |
| 忘記換箱、忘記換連隊、忘記素食 | 滿層叮一聲、滿箱跳封箱動畫、打完一連跳「下一個是誰、要幾箱」、素食那一格會變綠並提前提醒 |

## 裝箱規則

- 一個保麗龍箱 = **4 層 × 每層 6 個 = 24 個**
- **不同連隊不混裝**：每個連隊自己起箱，最後一箱不滿也沒關係
  （例：38 個 = 1 個滿箱 + 1 箱裝 14 個，用不到的格子會畫成虛線）
- **素食獨立標記**：`63+1素` 會算成 64 個，其中 1 個是素食，預設排在最後一格
  （設定裡可改成排最前）

## 怎麼用

### 1. 貼上班長的訊息

把 LINE 上的訊息整段複製貼上，按「✨ 自動解析」。支援這種格式：

```
明天便當數（7/28）禮拜二

八仙管理員
中：3
戰
早：中：15晚：63+1素
火
早：10中：30晚：20
ㄧ連
早：13中：26晚：38
二連
早： 中：15晚：31
三連
早：8 中：8晚：25
```

解析器對格式很寬鬆，這些狀況都吃得下：

- 全形／半形冒號、數字之間有沒有空白都可以
- 午餐寫「中」「午」「中午」「下午」都認得
- `早：` 後面沒填數字 → 當作 0
- 注音的「ㄧ連」也認得（跟漢字「一連」一樣）
- 素食寫成 `63+1素`、`15（2素）`、`20+素` 都可以
- 沒看過的單位（例如「兵器連」）會自動幫你新增
- 開頭的 `All`、日期那行不會被誤認成連隊

也支援**教召公版**那種「只有總數、沒有分早中晚」的寫法：

```
戰
建置（含訓員、義務役、協訓幹部）：45+1素
召員：79
安管：6個
總數：130+1素

五營（另外用沒貼連隊的保麗龍盒裝）
早上：0
中午：20
晚上：12
```

- **只認「總數」**，建置／召員／安管這些細項會自動略過
- 總數會套用到早／中／晚三餐（教召時三餐同一個數字）
- 有明確寫早／中／晚的餐別優先（例如上面的五營，三餐各自不同）
- 單位名稱後面的括號註記（例如「五營（另外用⋯⋯）」）會自動忽略
- 只寫「戰」「火」「一」也對得到戰支連／火力連／一連

還支援**駐地公版**那種「餐別當標題、數量前面掛駐地」的寫法：

```
8/6便當數量

早餐
戰支連
八仙130+1素
火力連
污水廠90+1素
二營47+1素
旅通砲78+2素
```

- **早餐／午餐／晚餐 當成區段標題**，底下所有單位都算那一餐
- **駐地名稱（八仙、污水廠、公民會館⋯⋯）只是前綴會被忽略**，數量算給上一行那個單位
- 單位名和數量寫在同一行也可以（`二營47+1素`）
- 同一個單位在三個餐別各出現一次，會自動合併，各餐數字可以不同
- 認得 步一連／步二連／步三連、二營、旅通砲

解析完會出現一張確認表格，數字都可以手動改，也能新增／刪除單位。

**換日會自動清空進度**：貼上的訊息日期跟目前記錄的不一樣時（例如昨天打完飯，今天貼新的），
所有餐別的已打數量會自動歸零，不用一餐一餐手動重設。同一天重複解析則會保留進度。

### 2. 開始打飯

- 上面選餐別（早／中／晚），一次專心打一餐
- 中間那張卡片就是你手上這一箱：4 層 × 6 格，**有光暈的那一格就是下一個要放的位置**
- 按底部的大 `+1`，每放一個便當按一下
- 放錯了按 `↺ −1`；漏掉一大段就直接點格子跳位（跨度大會先跟你確認）
- 打滿一連會自動跳到下一連，不用自己切
- **打到一半總數變了**（長官臨時來拿走便當）→ 按連隊名稱旁的「✏️ 改總數」，
  面板裡可以 `−1 / −2 / −5 / −10` 一次扣、用 `−` `＋` 微調，或直接輸入新的數字。
  **調完要按「套用」才會生效**，按取消不會動到資料，所以不怕誤按

### 3. 隨時掌握進度

- **最上面的看板**：這一餐還差幾個（大數字）。**素食另外打，所以大數字只算葷食**，
  素食掛在旁邊的綠色小標（`138 個 ＋1 素`）。下面三格小統計 —— 便當 `39/178`、
  箱數 `1/10`（這一餐封了幾箱／共幾箱）、🥬 素食總數
- **連隊小丸**：`戰 39/64`，下面一排是需求拆解 `63+1素` 與箱數 `📦 1/3 箱`
- 餐別分頁上有進度圈，打完會打勾
- 展開「本餐全連隊進度」可以看每一連已打幾箱幾個、還差幾個
- 展開「🥤 飲料箱數」可以看每一連的飲料要**共幾罐、幾箱又幾罐**（一個便當配一罐），
  最後一列是本餐合計（同樣是幾箱又幾罐，例如 269 罐 = 11 箱又 5 罐）。
  一箱幾罐可以改，預設 24，旁邊有 24 / 18 快速鍵

進度會自動存在瀏覽器裡，關掉再開會接續，不用怕手滑重整。

## 設定

齒輪按鈕裡可以調整：

- 🔊 音效提醒 / 📳 震動提醒（早點名怕吵可以關掉）
- 🎨 淺色 / 深色 / 跟隨系統
- 🥬 素食放最後（疊最上面好拿）或放最前
- ⏰ 開啟時自動選餐別（依時間：04:00–06:59 早餐、09:00–11:59 午餐、14:30–17:59 晚餐；
  不在時段內就選下一餐。**正在打到一半的餐別不會被搶走**）
- ✏️ 修改今天的便當數 · ↺ 重設本餐進度 · 🗑 全部清空

設定畫面裡每個單位有 `⌫` 可以把該單位的便當數歸零，底下也有「🧹 清空所有便當數」
（單位本身都會保留）。

## 開發

純 HTML / CSS / JavaScript，沒有任何套件、沒有 build step。

```bash
# 本機預覽
python3 -m http.server 8000
# 然後開 http://localhost:8000

# 跑解析器測試（不需安裝任何東西）
node tests/parser.test.js
```

推到預設分支後，GitHub Actions 會自動部署到 GitHub Pages。
