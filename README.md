# 🍱 飯飯之輩

給部隊打飯班用的便當分箱計數工具。貼上班長傳的訊息 → 自動算出每連幾箱幾個 → 一個一個按 `+1` 裝箱，換層、換箱、換連隊都會自動提醒。

**線上使用：** https://b09901017.github.io/army-meal-box-tracker/

手機瀏覽器打開後，可以「加到主畫面」，用起來就跟 App 一樣（也支援離線）。

---

## 解決什麼問題

打飯的時候最容易出包的三件事，這個工具都幫你顧著：

| 痛點 | 這裡怎麼處理 |
|---|---|
| 還差幾個便當要打？ | 最上面一個超大數字，隨時看得到 |
| 這連打到第幾箱、第幾個了？ | 每連獨立顯示「第 2 / 3 箱、本箱 15 / 24 個、已打 1 箱又 15 個」 |
| 忘記換箱、忘記換連隊、忘記素食 | 滿層叮一聲、滿箱跳封箱動畫、打完一連跳「下一個是誰、要幾箱」、素食那一格會變綠並提前提醒 |

## 裝箱規則

- 一個保麗龍箱 = **4 層 × 每層 6 個 = 24 個**
- **不同連隊不混裝**：每個連隊自己起箱，最後一箱不滿也沒關係
  （例：38 個 = 1 個滿箱 + 1 箱裝 14 個，用不到的格子會畫成虛線）
- **素食獨立標記**：`63+1素` 會算成 64 個，其中 1 個是素食，預設排在最後一格
  （設定裡可改成排最前）

## 怎麼用

### 1. 貼上班長的訊息

把 LINE 上的訊息整段複製貼上，按「✨ 自動解析」。支援這種格式：

```
明天便當數（7/28）禮拜二

八仙管理員
中：3
戰
早：中：15晚：63+1素
火
早：10中：30晚：20
ㄧ連
早：13中：26晚：38
二連
早： 中：15晚：31
三連
早：8 中：8晚：25
```

解析器對格式很寬鬆，這些狀況都吃得下：

- 全形／半形冒號、數字之間有沒有空白都可以
- 午餐寫「中」「午」「中午」「下午」都認得
- `早：` 後面沒填數字 → 當作 0
- 注音的「ㄧ連」也認得（跟漢字「一連」一樣）
- 素食寫成 `63+1素`、`15（2素）`、`20+素` 都可以
- 沒看過的單位（例如「兵器連」）會自動幫你新增
- 開頭的 `All`、日期那行不會被誤認成連隊

解析完會出現一張確認表格，數字都可以手動改，也能新增／刪除單位。

**換日會自動清空進度**：貼上的訊息日期跟目前記錄的不一樣時（例如昨天打完飯，今天貼新的），
所有餐別的已打數量會自動歸零，不用一餐一餐手動重設。同一天重複解析則會保留進度。

### 2. 開始打飯

- 上面選餐別（早／中／晚），一次專心打一餐
- 中間那張卡片就是你手上這一箱：4 層 × 6 格，**有光暈的那一格就是下一個要放的位置**
- 按底部的大 `+1`，每放一個便當按一下
- 放錯了按 `↺ −1`；漏掉一大段就直接點格子跳位（跨度大會先跟你確認）
- 打滿一連會自動跳到下一連，不用自己切

### 3. 隨時掌握進度

- **最上面的看板**：這一餐還差幾個（大數字），加上三格小統計 —— 便當 `39/178`、
  箱數 `1/10`（這一餐封了幾箱／共幾箱）、🥬 素食總數（單獨列，不跟葷食混在一起算）
- **連隊小丸**：`戰 39/64`，下面一排是需求拆解 `63+1素` 與箱數 `📦 1/3 箱`
- 餐別分頁上有進度圈，打完會打勾
- 展開「本餐全連隊進度」可以看每一連已打幾箱幾個、還差幾個
- 展開「🥤 飲料箱數」可以看每一連的飲料要幾箱又幾罐（一個便當配一罐）。
  一箱幾罐可以改，預設 24，旁邊有 24 / 18 快速鍵

進度會自動存在瀏覽器裡，關掉再開會接續，不用怕手滑重整。

## 設定

齒輪按鈕裡可以調整：

- 🔊 音效提醒 / 📳 震動提醒（早點名怕吵可以關掉）
- 🎨 淺色 / 深色 / 跟隨系統
- 🥬 素食放最後（疊最上面好拿）或放最前
- ✏️ 修改今天的便當數 · ↺ 重設本餐進度 · 🗑 全部清空

## 開發

純 HTML / CSS / JavaScript，沒有任何套件、沒有 build step。

```bash
# 本機預覽
python3 -m http.server 8000
# 然後開 http://localhost:8000

# 跑解析器測試（不需安裝任何東西）
node tests/parser.test.js
```

推到預設分支後，GitHub Actions 會自動部署到 GitHub Pages。

檔案結構與設計決策請看 [CLAUDE.md](CLAUDE.md)，開發紀錄請看 [docs/PROGRESS.md](docs/PROGRESS.md)。
